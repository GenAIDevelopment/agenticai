# What is a Datatype?

A **datatype** is a classification that specifies **what kind of values a variable can hold** and **what operations can be performed on it**.

## Quick Breakdown:

**Definition:** A datatype defines the nature, size, and range of data a variable can store.

## Main Categories:

### **1. Primitive/Basic Datatypes**
- **Integer** (int) - Whole numbers: -5, 0, 42
- **Float/Double** - Decimal numbers: 3.14, -2.5
- **Character** (char) - Single character: 'A', '5'
- **Boolean** (bool) - True or False
- **String** - Text: "Hello"

### **2. Composite/Derived Datatypes**
- **Arrays** - Collection of same type: [1, 2, 3]
- **Structures/Objects** - Multiple data types grouped
- **Pointers** - Memory address references

## Key Points to Remember:

| Aspect | Example |
|--------|---------|
| **Memory** | Different datatypes use different memory (int ≈ 4 bytes, char ≈ 1 byte) |
| **Operations** | You can add numbers but not directly concatenate them with text |
| **Type Safety** | Prevents errors (can't store "abc" in an integer) |
| **Default Values** | Different datatypes have different defaults |

## Simple Analogy:
**Datatype = Container Label**
- A "String" container holds text
- An "Integer" container holds whole numbers
- You can't put orange juice in a box labeled "apples"

---

**For exam:** Remember datatypes **classify** what data can be stored and **control** what operations are allowed! 🎯
